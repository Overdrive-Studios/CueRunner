Help

Answers to the questions that come up most.

The Mac app says it can't be opened

Right-click CueRunner in Applications and choose Open, then click Open again. If macOS says the app is damaged, open Terminal and run xattr -dr com.apple.quarantine /Applications/CueRunner.app, then try again.

Windows shows a warning when I run it

Choose More info, then Run anyway. The app isn't code-signed yet, so Windows doesn't recognise it.

How do I update?

Inside CueRunner, choose Help > Check for Updates. It downloads and installs the new version.

Command-comma doesn't open Settings on my Mac

Settings is in the CueRunner app menu on a Mac, with the shortcut Command-comma. Use the menu if the shortcut doesn't respond.

How do I control the show from my phone?

Start the phone remote from the Audio menu and choose a PIN. Then open the address it shows in a phone browser on the same network and enter the PIN.

Where are my show files backed up?

Each save copies the previous version into a backups folder next to the show file. CueRunner also takes a snapshot every 15 minutes, keeping the newest 20.
