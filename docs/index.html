Run your show from one place

CueRunner is a QLab-style show control app for Windows and Mac. Cues, a soundboard, venue radio, talkback and console control, all in one window.

Download CueRunnerSee features

Everything in one window

Cue list

Fades, loops, follow and continue, and a countdown.

Soundboard

64 pads in four banks, with ducking under talkback.

Consoles

Allen & Heath SQ, dLive, Avantis and Qu-5/6/7 over the network.

Phone and Stream Deck

Run the show from a phone browser behind a PIN, or a Stream Deck.
