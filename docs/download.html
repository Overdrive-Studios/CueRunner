Download CueRunner

Always the newest version. You only need to do this once; after that the app updates itself.

Windows

Run the downloaded file.

Download for Windows

If Windows shows a warning, choose More info, then Run anyway.

Mac

Open the disk image and drag CueRunner into Applications.

Download for Mac

The first time, right-click CueRunner and choose Open.

Install on a Mac

  1. Click Download for Mac and open CueRunner.dmg.
  2. Drag CueRunner into your Applications folder.
  3. Right-click CueRunner in Applications, choose Open, then click Open again.

Install on Windows

  1. Click Download for Windows and run CueRunner.exe.
  2. If Windows shows a warning, choose More info, then Run anyway.

Updates

Inside CueRunner, open Help > Check for Updates to install new versions. You won't need to come back here.

Previous versions and release notes are on GitHub Releases.
